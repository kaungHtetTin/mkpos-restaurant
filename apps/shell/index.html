Connect to your restaurant

Enter the address of your restaurant POS server. This app uses the same accounts, menu, orders and printers as your website.

For a local network, use the server computer’s address, such as http://192.168.1.10:8002. Use HTTPS for camera access.

Local mode stores data only on this PC. It does not sync with production.

The restaurant server must be running. On Android, localhost refers to the phone itself.
